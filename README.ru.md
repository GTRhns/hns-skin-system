# HNS Skin System · v4.0.0

> Counter-Strike 1.6 / AMX Mod X · независимая система скинов для серверов **GTR HNS (Hide & Seek)**.

![Аватар автора](assets/avatar.jpg)

**HNS Skin System v4.0.0** — новый независимый релиз серии `HnsSkin`. Он заменяет старый плагин `HnsMatchSkin` в ветке `main` и больше не использует конфиги, базу данных и монеты плагина матчей (`mixsystem`).

## Что нового в v4.0.0

- 🌍 **Английский по умолчанию, 4 языка** — English, 简体中文, 繁體中文, Русский. Если язык клиента не `cn` / `tw` / `en` / `ru`, через 2 секунды после подключения включается английский. Выбор языка через `/lang` сохраняется.
- 🗂 **Новое меню** — скины персонажей (TT / CT отдельно), ножи, гранаты (дым / вспышка), очки GBIC, цвет дыма, статус MySQL и админ-панель разделены. Вход по-прежнему `/skin`.
- 🔁 **Смена команды в deathmatch** — если игрока зарезали и перевели в другую команду без респавна, плагин в течение секунды применяет скин и нож этой команды.
- 💾 **Своя база и валюта** — собственные SQLite / MySQL и очки GBIC, без доступа к базе матча.

## Быстрая установка

1. Скопируйте `addons/` в `cstrike/addons/` на сервере.
2. Порядок загрузки в `configs/plugins.ini`:

   ```
   CustomPlayerModelsApi.amxx
   HnsSponsorLocal.amxx
   HnsSkin.amxx
   ```

   Для ножей нужен `crx_knife_models.amxx`, он должен загружаться **до** `HnsSkin.amxx`.
3. Не загружайте старый `HnsMatchSkin.amxx` вместе с новым плагином — оба регистрируют `/skin`.
4. Включите модуль `sqlite` в `modules.ini`; для очков и ежедневного бонуса нужен `nvault`.
5. Смените карту или перезапустите сервер.

Подробная установка: [`docs/安装说明.txt`](docs/安装说明.txt) (на китайском).

## Команды

| Команда | Доступ | Описание |
|---|---|---|
| `/skin` | все | магазин скинов |
| `/lang` | все | выбор языка (cn / tw / en / ru) |
| `/sign` | все | ежедневный бонус |
| `/cpm` | ADMIN_RCON | админ-меню |
| `amx_giveskin` / `amx_takeskin` / `amx_clearskin` | ADMIN_IMMUNITY | выдача / изъятие / очистка скинов |
