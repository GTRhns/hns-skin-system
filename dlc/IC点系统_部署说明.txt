# HNS IC 点系统 v2.0.0（完全独立版）

本插件**完全自包含**，不依赖任何比赛系统 / PersistentDataStorage，
仅依赖 AMX Mod X 内置模块（reapi / nvault），可直接独立运行。

> 发布位置：皮肤系统 DLC 目录（`dlc/`）。

## 文件

```
dlc/HnsICPointMenu.sma        → 插件源码
dlc/compiled/HnsICPointMenu.amxx → 编译产物（放入 plugins/）
dlc/ic_points.inc              → 供外部系统对接的 native 头文件
```

## 部署

1. 把 `HnsICPointMenu.amxx` 放入 `addons/amxmodx/plugins/`。
2. 在 `addons/amxmodx/configs/plugins.ini` 加一行：
   ```
   HnsICPointMenu.amxx
   ```
3. 确认 `configs/mixsystem/player_models.ini` 存在（皮肤兑换用它）。
4. 重启服务器或 `amxx load HnsICPointMenu.amxx`。

## 功能

- N 键（nightvision）打开 IC 点菜单（优先级高于 menu new）。
- 管理员给予 IC 点：`/givetic <玩家名|@ALL> <数量>`（需 admin 权限）。
- 积分兑换皮肤：人物 500 分 / 刀 300 分（CVAR 可配置）。
- 兑换皮肤直接应用模型，30 天自动清除。
- 积分与已兑换皮肤持久化（nvault，零额外依赖）。

## 对外接口（供比赛系统对接）

本插件**不内置比赛逻辑**，把发分接口开放给你自己的比赛系统。
在你的比赛系统里 `#include <ic_points>` 后调用：

```
ic_add_points(id, 10);        // 给玩家 +10 IC 点（在你认为合适的时机）
new pts = ic_get_points(id);  // 查询玩家当前 IC 点
```

发分时机/条件（如赢家+10、输家+5、参与奖励等）完全由你的比赛系统自行决定。

## CVAR

| CVAR | 默认 | 说明 |
|------|------|------|
| ic_skin_person | 500 | 兑换人物皮肤所需积分 |
| ic_skin_knife | 300 | 兑换刀皮肤所需积分 |
