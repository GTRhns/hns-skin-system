============================================================
  CS1.6 HNS 皮肤系统 v4.0.0  安装说明
  作者: OpenHNS
============================================================

【本版更新】
  - 默认语言改为英语, 同时支持 简体中文 / 繁體中文 / English / Русский
  - 菜单重新整理: 人物皮肤(TT/CT 分开)、刀皮、投掷物、点数、烟雾颜色、管理分开
  - 支持死斗模式换边: 换边后自动套用该玩家对应阵营的皮肤, 不需要重生
  - 皮肤商店使用自己的数据库和点数, 不读写比赛插件的 mixsystem / 金币

【依赖】
  - AMX Mod X 1.10 (ReAPI 版本)
  - 模块: sqlite (本地库) / nvault (点数与签到)
  - CustomPlayerModelsApi.amxx  (必须最先加载)
  - HnsSponsorLocal.amxx       (皮肤商店自己的 GBIC 点数)
  - HnsSkin.amxx               (主插件)
  - 可选: crx_knife_models.amxx (刀皮, 必须排在 HnsSkin.amxx 前面)
  - 可选: HnsLanguage.amxx      (语言核心; 客户端语言由它按人识别)

【安装】
  1. 把 addons/ 整个目录合并到服务器 cstrike/addons/ 下。
  2. 确认加载顺序 (configs/plugins.ini):
       CustomPlayerModelsApi.amxx
       HnsSponsorLocal.amxx
       HnsSkin.amxx
  3. 不要同时加载旧的 HnsMatchSkin.amxx, 两个插件都会注册 /skin。
  4. 刀皮要在 plugins.ini 里加载 crx_knife_models.amxx, 并排在 HnsSkin.amxx 之前。
  5. 打开 modules.ini 的 sqlite 模块; 点数/签到需要 nvault。
  6. 换图或重启服务器生效。

【语言】
  - 语言文件: addons/amxmodx/data/lang/hns_skin.txt
    段落: [cn] 简体 / [tw] 繁体 / [en] 英语 / [ru] 俄语
  - 默认英语: 进服 2 秒后, 客户端语言不是 cn/tw/en/ru 的玩家自动切到英语。
  - 玩家用 /lang 手动选过语言的, 保持玩家自己的选择, 不会被覆盖。
  - 客户端本身带 cn / tw / en / ru 语言的, 按客户端语言显示。

【数据库】
  默认本地 SQLite: addons/amxmodx/data/sqlite3/skinsql.sq3
  表由插件自动创建, 不需要手动导入 SQL。

  改用 MySQL:
    1. 复制 configs/skinsql/skinsql.cfg.example 为 configs/skinsql/skinsql.cfg
    2. 填写 skin_host / skin_user / skin_pass / skin_db
    3. 把 skins.cfg 顶部的 storage local 改成 storage mysql
    4. 换图/重启生效
  MySQL 必须用皮肤系统自己的库, 不要填比赛库。

【配置】
  configs/skinsql/skins.cfg
    [SETTINGS] 区块可改:
      storage          local / mysql
      rent_days        金币购买获得的租期天数, 0 = 直接永久 (默认 30)
      upgrade_price    限时皮肤升级永久的价格 (默认 2000 GBIC)
      knife_free       刀皮前 N 把免费
      nade_free        投掷物皮肤前 N 个免费
      checkin_bonus    每日签到奖励
      playtime_bonus   在线满 1 小时奖励
      precache_max     每张地图最多预缓存多少个皮肤模型
                       (CS1.6 模型池只有 512 个, 重型 HNS 地图容易崩服;
                        遇到崩服就调小, 例如 24 / 16)

  configs/skinsql/skins.cfg
    [T] / [TT]  恐怖分子款
    [CT]        反恐精英款
    每款两行:
      名字  模型路径  价格
      wav 音效路径            ; 可选, 属于上一款, 可写多行

  configs/skinsql/nade_skins.cfg   烟雾弹 / 闪光弹皮肤
  configs/skinsql/knife_skins.cfg  刀皮商店价格覆盖
  configs/KnifeModels.ini          刀模型定义 (crxknives 引擎读取)
  configs/custom_player_models.cfg 人物模型引擎参数 (自动生成, 一般不用改)

【菜单与命令】
  /skin      玩家皮肤商店
               1 人物皮肤 (TT / CT 分开)
               2 刀皮模型
               3 投掷物模型 (烟雾 / 闪光)
               4 GBIC 点数
               5 购买点数
               6 烟雾弹颜色
               7 MySQL 链接状态 (管理员)
               8 管理设置 (管理员)
  /lang      切换语言 (简体 / 繁体 / 英语 / 俄语)
  /sign      每日签到 (同 /checkin /qd /签到)
  /cpm       管理员菜单 (需要 ADMIN_RCON / A 权限)

  控制台 (管理员):
    amx_giveskin <steamid> <皮肤名|all|all_t|all_c|all_knife|all_nade>
    amx_takeskin <steamid> <皮肤名|all|all_knife|all_nade>
    amx_clearskin <steamid>

  后台发放 (玩家可以不在线, 写入 MySQL 后约 8 秒生效):
    INSERT INTO cpm_skin_grant (steamid, skin_key) VALUES ('STEAM_0:1:123456', '皮肤名');

【死斗换边】
  死斗模式被刀后当场换边、不重生时, 插件每秒检查一次队伍。
  发现阵营变了, 立即套用该玩家在那一侧的皮肤和刀皮, 不需要等重生。

【验证】
  - 玩家: /skin 能打开, 余额、皮肤列表正常
  - 管理员: /cpm 能发放 / 收回 / 查看皮肤池
  - 死亡音效: 选用带 wav 的皮肤, 死亡时能听到
  - 换边: 死斗被刀换边后, 皮肤跟着变成另一阵营的皮肤
  - 数据库: SELECT * FROM cpm_player_skins;  查看玩家拥有
            SELECT * FROM cpm_player_current; 查看当前选用
