# HnsSkin+IC 融合版使用教程 — 零基础也能装

> 面向：**任何想在 CS1.6 服务器里装上"皮肤 + IC 积分"的玩家 / 服主 / 开发者**
> 前提：**不需要会写代码**。本文从"第一步下载什么"讲起，一步一步带你装好、用好、还能自己加功能。
> 适用插件：`HnsSkin.amxx`（v3.0.0，融合版，一个插件搞定皮肤 + IC 积分）

---

## 一、先看懂：这个融合版是什么

以前，服务器里要装两样东西：

| 原来 | 功能 | 是个什么 |
|------|------|---------|
| `HnsSkin.sma`（皮肤系统） | 选皮肤、换皮肤、管理员发放 | 一个插件 |
| `HnsICPointMenu.sma`（IC 点系统） | 打比赛赚积分、用积分解锁皮肤 | 另一个插件 |

**两个插件装在一起，要各管各的存档、各开各的菜单，服主还得小心它们别打架。**

现在我们把它俩**融合成一个插件**（`HnsSkin.amxx`，v3.0.0），取各自的长处：

### 融合版保留了皮肤系统的长处

- 多类型皮肤选择：人物（T / CT）、刀、USP 手枪
- 共享皮肤模式（KZ 服 CT/T 共用一套人物皮肤）
- 管理员发放 / 收回皮肤（只认 `users.ini` 官方认证管理员，安全）
- 选择永久保存（nvault），玩家重连自动恢复
- 纯标准字段方案，兼容性好，不依赖额外插件

### 融合版保留了 IC 点系统的长处

- IC 积分体系：打比赛 / 活动获得，可累计
- 积分兑换皮肤：直接用积分解锁皮肤
- 对外接口 `ic_add_points` / `ic_get_points`：你的比赛系统可以自己对接发分
- 管理员直接给予 IC 点：`/givetic`

### 融合后的好处

- **只装一个插件**，省心
- **皮肤和积分共用一个存档**，不会乱
- **`/skin` 主菜单里直接就能看到你的积分、直接兑换**，不用再单独按 N 键
- 用积分兑换的皮肤，会**永久解锁**为你已拥有的皮肤（不是限时的），走皮肤系统统一的流程

> **分工一句话**：你的比赛系统 = 裁判（判断谁赢），融合版 = 账房（记分、扣分、存钱、换皮肤）。裁判只需朝账房喊一句"给某某加 10 分"。

## 三、部署：一步一步装到服务器

跟着做，每一步都别跳过。

### 第 1 步：把编译产物放进 plugins 目录

把 `compiled/HnsSkin.amxx` 复制到服务器的插件目录：

```
cstrike/addons/amxmodx/plugins/HnsSkin.amxx
```

### 第 2 步：在 plugins.ini 里启用

打开 `cstrike/addons/amxmodx/configs/plugins.ini`，在末尾加一行：

```
HnsSkin.amxx
```

### 第 3 步：放配置文件

把 `configs/player_models.ini` 复制到：

```
cstrike/addons/amxmodx/configs/player_models.ini
```

> 注意：如果你的服务器里已经有旧的皮肤系统，先把旧的 `HnsSkin.amxx` 从 plugins.ini 删掉，只留这一个融合版，避免两个插件抢同一个菜单、抢同一个存档。

### 第 4 步：重启服务器或换图生效

重启服务器，或在控制台输入：

```
amxx plugins
```

看到一个绿色勾的 `HnsSkin` 就说明加载成功了。

### 第 5 步：验证（可选）

进游戏，按 `Y` 输入 `/skin`。如果弹出"融合版皮肤系统"菜单，且能看到"IC 积分兑换"入口，就说明**融合版装好了**。

## 四、游戏内怎么用（玩家版）

不需要会代码，下面的命令直接用。

### 玩家命令

| 命令 | 功能 | 谁能用 |
|------|------|--------|
| `/skin` | 打开皮肤主菜单（含 IC 积分兑换） | 所有人 |
| `/skin_t` | 直接选 T 土匪皮肤 | 所有人 |
| `/skin_ct` | 直接选 CT 警察皮肤 | 所有人 |
| `/skin_knife` | 直接选刀皮肤 | 所有人 |
| `/skin_usp` | 直接选 USP 手枪皮肤 | 所有人 |
| `/ic` 或按 **N 键** | 打开 IC 点菜单（看积分 / 兑换） | 所有人 |

### 用 IC 积分兑换皮肤的流程

1. 按 `Y` 输入 `/skin`，打开主菜单
2. 选 **IC 积分兑换**（菜单右上角会实时显示你当前有多少分）
3. 选要兑换的类型：人物皮肤（T / CT）或刀皮肤
4. 积分够就成功解锁，积分不够会提示"积分不足 需要 X 分（当前 Y 分）"
5. 兑换的皮肤会**永久解锁**，之后在皮肤选择里直接就能用

> 默认价格：人物皮肤 500 分、刀皮肤 300 分（可在服务器配置里用 CVAR 改，见下文）。

## 五、管理员命令（服主 / 管理）

管理员命令**只认 `users.ini` 里的官方认证管理员**，其它的假管理权限一律无效——这是防止别人乱扣分、乱发皮肤的安全设计。

### 发 / 收皮肤

| 命令 | 功能 |
|------|------|
| `/giveskin` | 打开皮肤发放菜单 |
| `/giveskinmenu` | 同上（菜单发放） |
| `/giveallskins <玩家> <T/CT/Knife/USP/all>` | 批量发放皮肤 |
| `/giveskinid <玩家> <类型> <皮肤名>` | 命令行发放皮肤 |
| `/take <玩家> <类型> <皮肤名>` | 收回皮肤（需 users.ini 含 `o` 权限） |

### 发 / 收 IC 积分

| 命令 | 功能 | 例子 |
|------|------|------|
| `/givetic <玩家名> <数量>` | 给单个玩家加分 | `/givetic 小明 10` |
| `/givetic @ALL <数量>` | 给在线所有玩家加分（活动派发） | `/givetic @ALL 50` |

`/givetic`、`/giveic`、`/addic` 三个命令效果一样，看你哪个顺手。

> 加分成功后，玩家屏幕上会弹出 `[IC点] 获得+10分 (当前…)`。看到这行字说明积分系统跑通了。

## 六、让"打完比赛自动加分"（对接接口）

如果你想让比赛系统在比赛结束后自动给玩家发分，才需要看这一节。**不改代码就不需要看。**

### 全景：你接在哪里

```
玩家在服务器里
   │
   ├── 按 N 键 / 输入 /ic ──► 融合版（记分 + 存盘 ──► nvault 数据库）
   │                              └── 积分够了就兑换 ──► 皮肤
   │
   └── 打比赛 ──► 你的比赛系统（判断"谁该得分"）
                        │
                        └── 调用 ic_add_points(id, 分) ──► 融合版
```

融合版已经把"插口"准备好了，**一共就两个**：

| 插口 | 写法 | 意思 |
|------|------|------|
| ① 加积分 | `ic_add_points(id, 数量)` | 给某个玩家加多少分（最常用） |
| ② 查积分 | `ic_get_points(id)` | 查某个玩家现在有多少分 |

### 第 1 步：把"插头"放进工具箱

把仓库里的 `include/ic_points.inc` 复制到你的 AMXX 编译目录：

```
cstrike/addons/amxmodx/scripting/include/ic_points.inc
```

（和 `amxmodx.inc` 等放在一起）

### 第 2 步：在比赛系统源码顶部加一行

打开你比赛系统的 `.sma` 源码，在那一堆 `#include` 后面加这一行：

```pawn
#include <ic_points>
```

### 第 3 步：在"该发分的地方"调用

在你比赛系统里，找到"比赛结束 / 产生胜负"的那段代码，加上发分调用。例如：

```pawn
// 赢家 +10 分
ic_add_points(winner, 10);

// 输家 +5 分
ic_add_points(loser, 5);

// 想查一下某玩家现在多少分
new pts = ic_get_points(某玩家id);
```

**发分时机 / 条件完全由你的比赛系统决定**（赢家 +10、输家 +5、参与就 +1……全看你的规则）。融合版只负责记分、存盘、兑换皮肤，不替你决定谁该得分。

### 第 4 步：重新编译你的比赛系统

用 `amxxpc` 重新编译你的比赛系统 `.sma`，替换旧的 `.amxx`，重启服务器即可。

> 更详细的对接讲解（含"路 A 零代码 / 路 B 半自动 / 路 C 全自动"三条路）见 [《IC 点系统对接教程》](IC点系统对接教程.md)。

## 七、服务器配置（CVAR）

在 `server.cfg` 或 `amxx.cfg` 里可调这些参数：

| CVAR | 默认 | 说明 |
|------|------|------|
| `skinsys_shared` | `1` | 共享皮肤模式（KZ 服 CT/T 共用人物皮肤）。`0` = 关闭，T/CT 分开 |
| `skinsys_advanced` | `1` | 高级菜单开关 |
| `ic_skin_person` | `500` | 兑换人物皮肤所需积分 |
| `ic_skin_knife` | `300` | 兑换刀皮肤所需积分 |

例：把人物皮肤改成 800 分才能换：

```
ic_skin_person 800
```

## 八、皮肤怎么加（改配置文件）

皮肤模型在 `configs/player_models.ini` 里配置，格式：

```ini
[T]
显示名称 models/player/文件夹/模型.mdl

[CT]
显示名称 models/player/文件夹/模型.mdl

[Knife]
显示名称 models/v_knife.mdl

[USP]
显示名称 models/v_usp.mdl
```

- 往对应分区加一行，就多一个可选皮肤，菜单自动分页，不用改代码
- 刀模型只需填 `v_knife.mdl`，插件会自动处理第三人称
- 模型文件要放到服务器的 `models/` 目录下

## 九、常见问题

| 问题 | 解决办法 |
|------|---------|
| 插件没加载 | 看 `addons/amxmodx/logs/` 下的错误日志，确认模块齐全（reapi / nvault / hamsandwich 等） |
| 模型变成初始的 | 检查 `player_models.ini` 路径大小写是否一致、模型是否已 precache |
| 积分加了但没提示 | 确认发分命令是 `ic_add_points`，且玩家在线 |
| 菜单里没有 IC 兑换 | 确认用的是融合版 `HnsSkin.amxx`，且没有旧版皮肤插件抢菜单 |
| 想换积分价格 | 改 `ic_skin_person` / `ic_skin_knife` 这两个 CVAR |

## 第〇课 · 上课前，先认识你手里的东西

在讲任何命令之前，先弄明白三件事。这三件事是所有 CS 服务器插件的地基。

### 1. 你的服务器是什么

你的 CS 1.6 服务器，可以想象成一栋楼的**管理员办公室**。楼里住着玩家（土匪、警察），办公室里有各种管理工具。

| 中文说法 | English | 是什么 |
|---------|---------|--------|
| 服务器 | Server | 托管这局游戏的电脑（楼上管理员办公室） |
| 插件 | Plugin | 装进服务器的一段新功能代码（办公室里加的一台新机器） |
| CS 1.6 | Counter-Strike 1.6 | 这个游戏本身（这栋楼的名字） |

### 2. AMX Mod X 是什么

AMX Mod X（简称 AMXX）就像**办公室的电源总闸 + 插座系统**。它本身不干活，但它给"插件"提供了插电的地方。

```
┌─────────────────────────────────────────────────┐
│           你的 CS 1.6 服务器（整栋楼）            │
│                                                   │
│   ┌─────────────────────────────────────────┐    │
│   │   AMX Mod X（插座总闸）                  │    │
│   │   ┌──────────┐ ┌──────────┐ ┌────────┐ │    │
│   │   │ HnsSkin  │ │ 你的比赛  │ │ 其他插件│ │    │
│   │   │ 融合版    │ │   系统    │ │   ...   │ │    │
│   │   └──────────┘ └──────────┘ └────────┘ │    │
│   └─────────────────────────────────────────┘    │
│                                                   │
└─────────────────────────────────────────────────┘
```

**融合版插件 `HnsSkin.amxx` 就是插在 AMXX 这个大插座上的一个功能模块。** 它负责"皮肤"和"积分"这两件事。

### 3. 一套东西分三块：源码、编译产物、配置

一套插件有三个形态，很多新手会搞混，这里用"做饭"打比方讲清楚：

| 形态 | 中文 | English | 做饭的比方 |
|------|------|---------|-----------|
| 源码 | 原料 + 菜谱 | Source code | `.sma` 文件，是"配方和原材料说明" |
| 编译 | 下锅做菜 | Compile | 把 `.sma` 变成电脑认识的东西的过程 |
| 编译产物 | 做好的菜 | Binary | `.amxx` 文件，服务器直接"吃"这个 |
| 配置 | 放多少盐 | Config | `.ini` 文件，不用重新做菜也能调口味 |

> 普通人只需要"吃菜"（放 `.amxx` 和 `.ini`）。只有想改口味（加新功能）的人才需要看菜谱（`.sma`）。

## 第一课 · 这个融合版，到底同时干了哪两件事

前面说过它"融合了皮肤系统和 IC 点系统"。现在把这两件事拆开，配图讲清楚它内部的"分工"。

### 半边天之一：皮肤系统（Skin System）

任务：让玩家能换 T / CT / 刀 / USP 的皮肤，并且**永远记住**玩家选了哪个。

```
玩家输入 /skin
   │
   ▼
┌──────────────────────┐
│  皮肤主菜单           │
│  1. 人物皮肤          │
│  2. 刀皮肤            │
│  3. USP 皮肤          │
│  5. IC积分兑换  ←融合点  │
└──────────────────────┘
   │
   ▼ 玩家选了一个皮肤
┌──────────────────────┐
│  查：这个玩家拥有吗？   │
│  （查 nvault 存档）    │
└──────────────────────┘
   │ 拥有
   ▼
┌──────────────────────┐
│  套用模型 + 记进存档    │
│  （换外观 + 永久保存）  │
└──────────────────────┘
```

**关键工具 nvault**：这是 AMXX 自带的一个"小抽屉"，用来永久保存数据。服务器重启、玩家下线，数据都还在。

| 中文 | English | 作用 |
|------|---------|------|
| 存档 | nvault | 永久记住玩家拥有的皮肤、选中的皮肤、IC 积分 |
| 套用模型 | Apply model | 把玩家的外观换成选中的皮肤 |

### 半边天之二：IC 积分系统（IC Point System）

任务：记录玩家赚了多少积分，让玩家用积分兑换皮肤，并且把"怎么发分"的插口开放给比赛系统。

```
你的比赛系统（裁判）                融合版（账房）
      │                                │
      │  ic_add_points(玩家id, 10)      │
      ├───────────────────────────────►│
      │                                │  记一笔账（存进 nvault）
      │                                │
      │                 玩家按 N 键 /ic │
      │  ◄────────────────────────────│
      │                                │  显示当前积分
      │                                │  玩家选"积分兑换皮肤"
      │                                │  扣分 + 解锁皮肤
```

| 中文 | English | 一句话 |
|------|---------|--------|
| 积分 | Points / IC points | 玩家通过比赛或活动赚到的"货币" |
| 兑换 | Redeem | 用积分换皮肤 |
| 插口 | Interface / Native | 让别的插件能调用你的功能 |

### 融合点：为什么这两个能合在一起

因为**积分兑换皮肤的最终结果，就是"拥有一个皮肤"**。而"拥有皮肤"这件事，皮肤系统早就做好了。所以融合版做的是：

```
IC 积分兑换
   │   扣掉积分（账房记账）
   ▼
解锁为"已拥有皮肤"（皮肤系统老本行）
   │   走皮肤系统的统一流程
   ▼
套用模型 + 永久保存（nvault）
```

**这就是"取各自长处"的意思**：皮肤的成熟流程 + 积分的经济玩法，拼在一起，谁也不重复造轮子。

## 第二课 · 用一张图看懂：整个系统的"通关流程"

把上面两件事拼成一张完整的地图。这张图你可以把它贴在屏幕边，后面所有课都是围着它讲的。

## 第三课 · 配置文件的逐行讲解（老师逐字教你读）

很多新手看到配置文件就头大。其实配置文件的规则就一句话：**"名字 + 路径"**。

### player_models.ini —— 皮肤清单

```
[T]
显示名称 models/player/文件夹/模型.mdl
```

| 位置 | 中文意思 | English | 说明 |
|------|---------|---------|------|
| `[T]` | 土匪分区 | T section | 这一块下面的都是土匪能用的皮肤 |
| `显示名称` | 菜单里显示的名字 | Display name | 玩家在菜单里看到的名字，随便起 |
| `models/...mdl` | 模型文件路径 | Model path | 模型真身放在服务器的这个位置 |

**加一个皮肤 = 在对应分区加一行。** 插件会自动把它变成菜单里的一项，不用改代码。

```
[T]
默认土匪 models/player/arctic/arctic.mdl
熊猫大侠 models/player/panda/panda.mdl   ← 新增这一行 = 多一个皮肤
```

### 三个 CVAR —— 数字开关

CVAR 是 AMXX 世界里的"旋钮"，用来随时调参数，不用改代码重编译。

| CVAR | 默认 | 中文 | English | 一句话 |
|------|------|------|---------|--------|
| `skinsys_shared` | `1` | 共享模式 | Shared mode | T 和 CT 用同一套人物皮肤（KZ 服友好） |
| `ic_skin_person` | `500` | 人物皮肤价格 | Person skin price | 换人物皮肤要多少分 |
| `ic_skin_knife` | `300` | 刀皮肤价格 | Knife skin price | 换刀皮肤要多少分 |

> 改法：打开 `server.cfg` 或 `amxx.cfg`，写一行 `ic_skin_person 800`，保存，换图生效。

## 第四课 · 对接比赛系统：从"完全不改"到"全自动"三级跳

前面教程讲过对接，这里用**老师出练习题**的方式，让你真正理解"插口"这个东西。

### 插口到底是个什么？

想象墙上的电源插座。插座上写着"220V 交流电"。你不需要知道发电厂怎么发电，只需要知道**插头格式对上，就能有电**。

IC 点系统的插口有两个，格式已经定好：

| 插口 | 中文 | English | 你要做的就是 |
|------|------|---------|-------------|
| `ic_add_points(id, 数量)` | 加分插口 | Add points | 把"谁+多少分"告诉它 |
| `ic_get_points(id)` | 查分插口 | Get points | 问它"这人多少分" |

### 三级跳：根据你的水平选一档

| 档位 | 中文 | English | 你要做的 | 效果 |
|------|------|---------|---------|------|
| 第一级 | 零代码 | Zero-code | 什么都不改 | 管理员手动 `/givetic` 加分 |
| 第二级 | 接上线 | Wire up | 复制 1 个头文件 + 加 1 行 include | 你的插件能"认识"插口 |
| 第三级 | 全自动 | Full-auto | 在比赛系统加 2~3 行调用 | 打完比赛自动发分 |

### 第三级全自动，完整走一遍（老师陪你敲）

目标：让"赢家 +10 分"自动发生。

**第 1 步**：把 `ic_points.inc` 复制到编译目录的 include 文件夹：

```
cstrike/addons/amxmodx/scripting/include/ic_points.inc
```

**第 2 步**：打开你的比赛系统 `.sma`，在顶部 `#include` 后面加一行：

```pawn
#include <ic_points>
```

**第 3 步**：找到"比赛结束判胜负"的那段代码，加上：

```pawn
// 比赛结束，判断赢家
if (team_won == TEAM_T) {
    // 给所有 T 队玩家 +10 分
    ic_add_points(winner_player, 10);
}
```

**第 4 步**：重新编译，替换 `.amxx`，重启服务器。

### 老师帮你避免的三个坑

| 坑 | 中文 | English | 怎么避开 |
|----|------|---------|---------|
| 坑 1 | 玩家没在线 | Player offline | `ic_add_points` 前先确认玩家在线，否则无效 |
| 坑 2 | 数量写反了 | Wrong order | 顺序是 `(玩家id, 数量)`，别写成 `(数量, 玩家id)` |
| 坑 3 | 忘了编译 | Forgot to compile | 改完 `.sma` 必须重新编译才有 `.amxx` |
