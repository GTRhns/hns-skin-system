# 版本历史归档

本目录集中存放 HnsSkin 独立皮肤系统的**所有历史版本源码备份**，每个版本独立子目录，便于查阅、对比与回滚。

> 每个版本目录内含：
> - `HnsSkin.sma` — 该版本的完整源码
> - `VERSION.md` — 版本标识 + 该版本的【更新内容 / 更改内容 / 修复内容】

---

## 版本一览

| 版本 | 日期 | 版本标识 | 定位 | 源码行数 |
|------|------|---------|------|---------|
| [v1.0.0](v1.0.0/) | 2026-08-06 | `1.0.0` | 初始稳定版（T/CT/刀 + nvault 持久化） | 2175 |
| [v1.1.0](v1.1.0/) | 2026-08-10 | `1.0.0` | 功能增强版（+USP 皮肤 + 多项修复） | 2504 |
| [v2.0.0](v2.0.0/) | 2026-08-10 | `2.0.0` | 当前推荐版（+WPM 第三人称刀皮） | 2524 |

> 说明：v1.0.0 与 v1.1.0 源码内的 `PLUGIN_VERSION` 宏均声明为 `1.0.0`（历史版本未及时更新版本号宏），本目录以**文件实际内容差异**划分版本。

```
v1.0.0 ──► v1.1.0 ──► v2.0.0（当前）

  │           ├─ 新增 USP 皮肤
  │           ├─ 修复换队/切武器/切刀模型丢失
  │           └─ 菜单 UI 美化
  │

              │
              └─ 接入 WPM API，第三人称刀皮稳定渲染
```

---

## 如何选择版本

- **稳定使用 / 推荐**：`v2.0.0`（即仓库根目录中的 `HnsSkin.sma`）。
- **不需要 WPM / 服务器无 follow 实体支持**：可回退到 `v1.1.0`。
- **需要最基础皮肤功能**：`v1.0.0`。

如需回滚，将对应版本目录的 `HnsSkin.sma` 复制到 AMXX `scripting/` 目录重新编译即可。
