# HnsSkin v1.0.0 — 初始稳定版

> 独立皮肤系统首版发布。本目录为历史版本源码备份，仅供查阅与回滚使用。

- **版本号**：`1.0.0`
- **发布日期**：2026-08-06
- **插件标识**：`HnsSkin Skin System`（`#define PLUGIN_VERSION "1.0.0"`）
- **文件清单**：
  - `HnsSkin.amxx` — 编译插件（可直接部署）
  - `HnsSkin.sma` — 完整源码（2175 行）
- **协议**：GPLv3

---

## 更新内容（首版包含）

| 模块 | 说明 |
|------|------|
| 皮肤加载 | 支持 T / CT 阵营皮肤与刀皮肤（`v_knife.mdl` 渲染） |
| 皮肤发放 | 管理员 `/giveskin`、`/giveallskins`、`/giveskinid` 发放 |
| 分页菜单 | `/skin` 分页选择菜单，T / CT / 刀三个子菜单 |
| 数据持久化 | `nvault` 保存玩家拥有的皮肤与当前选择，断线重连不丢失 |
| 玩家鉴权 | 按 SteamID（正版）或 IP（盗版）识别玩家 |

## 更改内容

- 无（初始版本）。

## 修复内容

- 无（初始版本）。
