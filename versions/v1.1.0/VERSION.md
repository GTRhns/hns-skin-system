# HnsSkin v1.1.0 — 功能增强版

> 独立皮肤系统功能增强版。本目录为历史版本源码备份，仅供查阅与回滚使用。

- **版本号**：`1.1.0`
- **发布日期**：2026-08-10
- **插件标识**：`HnsSkin Skin System`
- **文件清单**：
  - `HnsSkin.amxx` — 编译插件（可直接部署）
  - `HnsSkin.sma` — 完整源码（2504 行）
- **协议**：GPLv3

---

## 更新内容（新增）

| 新增 | 说明 |
|------|------|
| **USP 皮肤系统** | 新增第一人称 USP 枪械皮肤支持，玩家可选择自定义 USP 模型 |
| `/skin_usp` 命令 | 直接打开 USP 皮肤选择菜单 |
| USP 皮肤回退机制 | 所选自定义模型不存在时自动回退默认 USP，避免视角模型丢失/报错 |
| `set_player_usp_view()` | 新增 USP 模型应用函数 |
| `count_owned_skins()` | 新增已拥有皮肤计数函数 |

## 更改内容

- 菜单 UI 全面美化（多色红/绿/蓝配色，GitHub README 徽章同步更新）。
- 重构皮肤应用逻辑，统一 T / CT / 刀 / USP 的模型设置入口。

## 修复内容

| 修复 | 说明 |
|------|------|
| 换队后皮肤不刷新 | 捕获 `TeamInfo` 事件，玩家换队时立即重新套用对应阵营皮肤 |
| 切武器视角模型丢失 | 新增 `Ham_Item_Deploy` 钩子，切到刀/USP 时自动重新应用已选皮肤 |
| 刀皮肤切换丢失 | 修正 `CurWeapon` 消息拦截逻辑，切刀时视角内模型保持正确 |
| 模型缺失兼容 | 皮肤文件不存在时安全回退默认模型，不再闪成原始模型或报错 |

---

## 部署依赖

- AMX Mod X 1.8.3+ / ReGameDLL 5.x
- 模块：`amxmodx`、`fakemeta`、`amxmisc`、`reapi`、`nvault`、`hamsandwich`

---

## 升级提示

- 直接替换 `HnsSkin.sma` 编译后的 `.amxx` 并覆盖 `player_models.ini`（新增 `[USP]` 分区）即可。
- 已有玩家皮肤数据（nvault）不受影响，自动保留。
